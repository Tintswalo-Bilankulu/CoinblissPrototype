Accessibility

Built to be read and operated clearly.

CoinBliss is a static study aid. These are the measures in the interface, and the limits that still apply.

How to use it

Keyboard
Every page starts with a skip link. Menus, forms, and buttons can be reached with Tab, and the focus ring stays visible.
Text
Copy uses a readable size and ordinary HTML headings, so browser zoom and text spacing still work.
Colour
Navy text on warm paper is the default. Figures that are over budget are also described in words, not by colour alone.
Forms
Each field has a visible label. Errors are written next to the form, not only in a pop-up.
Motion
The interface does not depend on animation. If your system asks for reduced motion, smooth scrolling is turned off.

Known limits

Some resource links leave CoinBliss for other sites, and those sites set their own accessibility. Budget and expense figures are saved only in this browser. There is no published support inbox for this prototype.
