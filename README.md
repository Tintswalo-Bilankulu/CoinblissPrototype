# CoinBliss — Personal Finance Prototype

CoinBliss is a personal finance application prototype exploring how a clear, usable interface can help people track spending and manage budgets.

Developed as an academic project, it applies Human-Computer Interaction (HCI) principles and business systems thinking to everyday financial tasks.

## Project Purpose

The project explores how user-centred design can make budgeting and financial tracking easier to understand.

Its objectives are to:

- Support clearer budget planning and spending awareness.
- Translate user needs into feature concepts and user flows.
- Present financial information through an understandable interface.

## Prototype Scope

| Area | Intended Purpose |
| --- | --- |
| Budget calculation | Help users work through a personal budget. |
| Expense tracker | Support the tracking and review of spending. |
| Resources page | Provide a space for financial information and learning resources. |
| Profile page | Organise user profile information. |

These areas represent the prototype’s intended user experience.

## Design Approach

The design focuses on clear navigation, understandable information and logical task sequences.

HCI principles guide how users move through the proposed budgeting and spending workflows. The project connects identifying user needs with defining features and designing the interactions that support them.
